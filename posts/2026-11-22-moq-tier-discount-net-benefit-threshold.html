MOQ 阶梯折扣别只看折扣率：跨档采购的净收益分界

2026-11-22 · 商业操盘

供应商给阶梯价，多数团队按折扣率高低拍板：5% 比 3% 好，能跨档就跨。把六个 SKU 的账摊开，结论是反的——折扣节省只站在收入这一侧，另一侧压着资金占用、仓储与贬值三笔持有成本，还有季节性 SKU 的尾货沉淀；唯一能对冲的是一个最容易被漏掉的项：断货不再发生、毛利润没有丢掉的那部分。年采购额 592.10 万元，账面折扣 26.23 万元，扣完这三块只剩 12.26 万元，占采购额 2.07%。六类里 4 类该跨档、2 类必须留在本档；若按折扣率无差别全跨，年净收益掉到 6.23 万元，账面口径高估 2.14 倍。

一、折扣率不能和持有成本率直接比：压仓月数是隐藏乘数

误判发生在任何算术之前：把折扣率和资金成本率放在一起看。“月资金成本 0.667%，折扣 3.5%，划算”——这个比较漏了压仓月数。折扣是一次性的，持有成本是按月走的时间账，两者之间差一个乘数：这批货你要多压几个月。3.5% 的折扣，若多压 3 个月，按 2.97%/月的持有成本算就是 8.91%，已经反超。

六个 SKU 的覆盖月数从 1.88 到 4.06，差 2.2 倍。试试最容易想到的简化指标——折扣率 ÷ 覆盖月数，当作月度净率看：S1 收纳箱 1.87%，S5 防潮垫 1.85%，几乎一模一样，但一个该跨档、一个必须不跨。这个指标在真实数据上直接失效，所以下面全部改用净收益口径。

二、净收益的四个组成：折扣节省、持有成本、尾货沉淀、缺货对冲

折扣节省最直观：跨档后的单价乘以跨档数量。持有成本按月率 m = 资金 0.667% + 仓储摊销 1.5% + 贬值 0.8% = 2.97%，作用在平均多压的库存上——库存从本档爬到下一档，取一半作为均值——再乘沉淀月数。尾货沉淀只咬季节性 SKU：季末卖不掉的按折价率 k 损掉，比例用历史尾货率 φ 估。尾货这一项的杀伤力取决于产品结构，不取决于供应商。

第三块是团队最容易漏的，而且不小：库存压厚了，断货概率下降，没丢掉的毛利就回来了。它凭什么算进采购决策？因为断货丢的是毛利润——不是运费，也不是折扣——而毛利润和你在谈的那点折扣，在同一张损益表上。按断货率差乘月销量、再乘单价与毛利率 0.42 算回。

三、闭式阈值：临界折扣率 d* 是怎么算出来的

令净收益为零，解出临界折扣率。结构可读：持有项带 Δ²/(4D)——跨档量翻倍，多压的件数和压着的月数一起涨，所以是平方；尾货项带 k·φ，是线性的；缺货对冲是唯一的减项，权重看客单价与毛利率。d* 高于合同折扣，这一档就不该跨。

d* = [ p·m·Δ² / (4D) + p·k·φ·Δ − D·a0·(1 − 1/T)·p·G ] / (Q1·p)

式中：Δ = Q2 − Q1 为跨档多压件数，D 为月销量，Q1 为本档量、Q2 为下一档量，T = Q2 / D 为覆盖月数；p 为采购单价，m = 2.97%/月 为月度持有成本率，k 为尾货折价率，φ 为尾货率，a0 为现断货率，G = 0.42 为毛利率。

六个输入里，四个是合同或历史：单价、两档数量、尾货折价与尾货率；两个是判断：月度持有成本率、现断货率。所以 d* 不是供应商给的数，是你自己算出来的数。公式还说明一件反直觉的事：同一笔折扣，覆盖月数拖得越长，缺货对冲的力度越大（T 从 2 到 4，系数从 0.5 到 0.75），但持有成本是平方级上涨——这就是为什么“多压一点更安全”在低价高频品上成立，在高单价季节性品上不成立。

先看两个失败案例，教训都在这里。S2 折叠椅拿到全场最高的 5.00% 折扣，一个周期省 13,440 元；但它的覆盖月数拖到 3.29，尾货率 42%，光尾货沉淀就 22,982 元，是折扣的 1.7 倍，净 −11,615 元，临界 d* 9.32%——供应商得给到 9.32% 这笔账才持平，桌上是 5%。S5 防潮垫重复同一个剧本：7.50% 的折扣看着最诱人，尾货沉淀 17,184 元对折扣 13,260 元，临界 d* 10.94%。

过线的四类是同一套算术的另一半。S1 收纳箱覆盖 1.88 个月、尾货率 6%：折扣 7,980 元对持有 691 元加尾货 958 元，净 +7,165 元/周期，年化 45,858 元，临界 0.36%。S6 保温水壶的折扣只有 2.50%，全场最小，但覆盖 2.00 个月、尾货率 8%，临界 d* 只有 0.85%，2.5% 轻松过线，年化 13,347 元。S4 地钉套装折扣绝对额最大（16,500 元），年化却是四类里最低的 26,394 元——月销 5,600 件对 22,000 件的档位，一年只走 3.05 个采购周期。

七、反向论证：谈判桌上更值钱的不是跨档，是年框锁价

表 6：年框锁价与阶梯跨档的对照（元/年）。锁价净收益 = 年采购额 × 折让 − 30% 预付款 × 8% 资金成本；临界折让 2.40%。

方案 年净收益（元） 对阶梯跨档（122,574） 倍数
锁价折让 3% +35,526 −87,048 0.29×
锁价折让 5% +153,947 +31,373 1.26×
锁价折让 8% +331,578 +209,004 2.70×
阶梯跨档（阈值口径） +122,574 — 1.00×

这才是分析该改变对话的地方。同样 592.10 万元的采购额，谈成 12 个月平价锁价，根本不产生跨档库存：收益就是采购额乘折让，唯一成本是 30% 预付款按 8% 计的资金占用，临界折让 2.40%。给到 5% 锁价净 15.39 万元，给到 8% 是 33.16 万元，两个都超过把六个 SKU 的阶梯折扣算到底的 12.26 万元，而且不增加一分钱库存。

但别急着改口，两个反面的账必须算。第一，预付款是现金出去的：30% 的 592.10 万元是 177.63 万元，直接从周转里抽走，对现金流吃紧的矩阵，这不是免费的。第二，平价锁价是一笔“价格不会跌”的赌注：如果中途供应商自己的目录价降了 6%，你锁的 8% 并没有换来任何额外的东西。所以结论是一个比较式而不是一句口号：当锁价折让 > 阶梯折扣净收益 + 保持灵活性的期权价值，才该改谈锁价。

八、季度动作：把档位判断压成一张表

第一步，每个 SKU 算出覆盖月 T 与临界折扣 d*，做成一张两列的表，挂在采购共享盘上。第二步，采购时只按 d ≥ d* 跨档，d < d* 留本档、接受分批到货，把“能不能跨”变成“该不该跨”。第三步，把尾货率 φ 接进季末清仓复盘——它是唯一能翻转结论的参数，每季度重算一次。第四步，谈判时把 d* 表摆出来：供应商的档位是固定的，你的 d* 是算出来的，谁手里有表，谁在定价格。

一个执行细节：这张表对 m 不敏感，但对 m 的两项最容易被拍脑袋——1.5% 的仓储摊销和 0.8% 的贬值率。仓储要用自有仓的真实单件存储成本（租金、人力、货架折旧摊到件），不要用行业均值；贬值率用过去 12 个月的实际跌价记录，不要用财务的存货跌价准备，后者是会计估计，不是现金损失。估错这两项不会改结论，但会让你的年净收益数字上下浮动两成。

九、结语：杂于利害

《孙子·九变》讲“是故智者之虑，必杂于利害。杂于利而务可信也，杂于害而患可解也”。阶梯折扣就是这句话的标准题型：折扣率是利，尾货率是害，两个数必须落在同一张表上算，单看任何一个都会做错。S2 那个 5.00% 是全场最高的折扣，也是全场最贵的一档——恰恰因为它看上去最划算。

附：可复现脚本（Python 3，仅标准库）

下面这段跑出表 1 到表 6 的全部数字，不依赖任何第三方包。换自己的数据只改 SKUS 一处，m、WACC、PREPAY 三个参数在顶部。

# moq_tier.py -- MOQ tier-discount net benefit (standard library only)
M = 0.0067 + 0.0150 + 0.0080   # monthly carrying rate: capital + warehouse + drift
G = 0.42                        # gross margin, used to value the stockout recovery
WACC = 0.08                     # annual cost of capital
PREPAY = 0.30                   # prepay share demanded by a 12-month price lock

# name, unit cost, monthly demand, tier qty, next tier qty, discount, markdown, leftover rate, stockout rate
SKUS = [
    ("S1 storage box", 38.0, 3200,  3200,  6000, 0.035, 0.15, 0.06, 0.035),
    ("S2 folding chair", 96.0,  850,   900,  2800, 0.050, 0.30, 0.42, 0.040),
    ("S3 camp lantern",  52.0, 2100,  2100,  5000, 0.040, 0.20, 0.09, 0.045),
    ("S4 peg set",       12.5, 5600,  5600, 22000, 0.060, 0.18, 0.11, 0.030),
    ("S5 moisture mat",  68.0,  640,   700,  2600, 0.075, 0.35, 0.38, 0.050),
    ("S6 water bottle",  45.0, 1500,  1500,  3000, 0.025, 0.22, 0.08, 0.038),
]


def one(p, D, q0, q1, d, k, phi, a0, m=M):
    delta = q1 - q0                          # extra units held after the step-up
    t1 = q1 / D                              # months of cover on the new tier
    save = q1 * p * d                        # discount captured on the whole order
    hold = p * m * delta * delta / (4 * D)   # avg extra stock x months held
    dead = p * k * phi * delta               # leftover written down at season end
    stock = D * a0 * (1 - 1 / t1) * p * G    # stockout recovered, 1/T decay
    net = save - hold - dead + stock
    dstar = (hold + dead - stock) / (q1 * p)
    cyc = 12 * D / q1                        # purchase cycles a year
    return dict(save=save, hold=hold, dead=dead, stock=stock, net=net,
                dstar=dstar, cyc=cyc, annual=net * cyc, t1=t1)


def table(m=M):
    return [dict(one(*s[1:], m=m), name=s[0]) for s in SKUS]


def flip_phi(s):
    _, p, D, q0, q1, d, k, _, a0 = s
    lo, hi = 0.0, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        if one(p, D, q0, q1, d, k, mid, a0)["net"] < 0:
            hi = mid
        else:
            lo = mid
    return (lo + hi) / 2


R = table()
print("%-17s %6s %8s %7s %8s %8s %8s %8s %8s" %
      ("SKU", "cover", "discount", "carry", "leftover", "stockout", "net/cyc", "annual", "d*"))
for r in R:
    print("%-17s %6.2f %8.0f %7.0f %8.0f %8.0f %+8.0f %+8.0f %7.2f%%" %
          (r["name"], r["t1"], r["save"], r["hold"], r["dead"], r["stock"],
           r["net"], r["annual"], r["dstar"] * 100))

spend = sum(s[1] * s[2] * 12 for s in SKUS)
paper = sum(s[1] * s[2] * 12 * s[5] for s in SKUS)
thr = sum(r["annual"] for r in R if r["net"] > 0)
allcross = sum(r["annual"] for r in R)
print("\nspend %.0f | paper %+.0f | threshold %+.0f (%.2f%%) | step-up-all %+.0f (%.2f%%)" %
      (spend, paper, thr, thr / spend * 100, allcross, allcross / spend * 100))
print("threshold - all %.0f | paper / threshold %.2f x" % (thr - allcross, paper / thr))

print("\n== carrying-rate sensitivity ==")
for mm in (0.0217, M, 0.0400, 0.0550):
    rs = table(mm)
    print("m=%.2f%% " % (mm * 100) +
          " ".join("%s:%+7.0f" % (r["name"][:2], r["annual"]) for r in rs) +
          " cleared=%d net=%+.0f" % (sum(1 for r in rs if r["net"] > 0),
                                     sum(r["annual"] for r in rs if r["net"] > 0)))

print("\n== leftover-rate flip point ==")
for s in SKUS:
    print(s[0], "phi*=%.1f%%" % (flip_phi(s) * 100))

print("\n== 12-month price lock ==")
for g in (0.03, 0.05, 0.08):
    lock = spend * g - spend * PREPAY * WACC
    print("concession %.0f%% lock net %+.0f vs tier %+.0f" % (g * 100, lock, thr))
print("lock break-even concession g* = %.2f%%" % (PREPAY * WACC * 100))

输出要点：六类年化 +45,858、−42,312、+36,976、+26,394、−17,967、+13,347 元；年采购额 5,921,040 元、账面折扣 262,266 元、阈值口径 122,574 元（2.07%）、全跨档 62,295 元（1.05%）；m 四个取值下过线恒为 4 类；锁价临界折让 2.40%，8% 折让净 331,578 元。
