大促复盘别只看 GMV：五层净利拆解做成 AI 技能包

2026-10-20 · AI 技能包

双 11 之后第一个工作日，运营群里最常见的报喜是"GMV 破 X 万"。这句话不假，但它回答不了财务的下一个问题：净利是多少。做操盘十五年，我的结论是：大促复盘的价值不在 GMV 高低，而在能不能把 GMV 拆到"实收净利"这一层——拆得清，下次才投得准。

一、大促复盘的第一道坎：GMV 不是钱

GMV 是"下单口径"，不是"到账口径"。退款、售后、仅退款、拒签、平台扣点都发生在 GMV 之后。用公开可验证的口径举例：罗技天猫旗舰店首年 GMV 2171 万、次年 4897 万（本号简历公开数据），SanDisk 京东自营从 7 千万增长到 2.13 亿——这些数字记录的是"卖出去多少"，没记录"赚回来多少"。同一条增长曲线，折扣换量和净利换量是两种完全不同的生意。

二、五层净利拆解：从 GMV 到实收净利

把 GMV 到净利之间的水份一层层挤掉，我固定用五层口径。口径一旦固定，人人都能对账：

层公式含什么
1 · 实收销售额GMV − 退款未发货退款、售后、拒签、仅退款
2 · 平台后收入实收 × (1 − 平台综合扣点)佣金、支付通道费、技术服务费
3 · 履约后收入平台后 − 物流 − 包装快递费、包材、退货运费
4 · 营销后收入履约后 − 投放 − 佣金 − 其他变动广告、达人佣金、优惠券、运费险
5 · 实收净利营销后 − 固定成本分摊仓储、人力、水电、折旧

三、真实数据回放：一场 86 万大促的净利结构

以 2026 年双 11 一场台球器材大促为例（脱敏示例数据，口径与本号简历披露一致）：

口径金额（元）
GMV860,000
退款（5%）43,000
平台综合扣点 12%（按实收 817,000）98,040
物流与包装26,000
投放88,000
达人佣金34,400
运费险 / 优惠券等其他变动12,000
固定成本分摊58,000

五层跑完：实收 817,000 → 平台后 718,960 → 履约后 692,960 → 营销后 558,560 → 净利 500,560。GMV 86 万看着热闹，净利率 58.2% 是"没有价格战"的理想结构；把五层参数代入脚本，30 秒能重算任何一场大促。

def net_profit_layer(gmv, refunds=0.05, platform_rate=0.12, logistics=0.0,
                     ads=0.0, commission=0.0, other=0.0, fixed=0.0):
    """五层净利拆解：从 GMV 到实收净利。"""
    l1 = gmv * (1 - refunds)                 # 层1 实收销售额
    l2 = l1 * (1 - platform_rate)            # 层2 平台后收入
    l3 = l2 - logistics                      # 层3 履约后收入
    l4 = l3 - ads - commission - other       # 层4 营销后收入
    l5 = l4 - fixed                          # 层5 实收净利
    return {
        "gmv": gmv, "layer1": round(l1, 2), "layer2": round(l2, 2),
        "layer3": round(l3, 2), "layer4": round(l4, 2), "layer5": round(l5, 2),
        "net_margin": round(l5 / gmv, 4),
    }

r = net_profit_layer(gmv=860_000, refunds=0.05, platform_rate=0.12,
                     logistics=26_000, ads=88_000, commission=34_400,
                     other=12_000, fixed=58_000)
print(r)

四、把五层净利拆解做成 AI 技能包

复盘点要变成资产，就得封装成技能包：写清 SKILL.md 的输入输出和校验规则，让下一个人（甚至零基础同事）复制即用。

# 技能包：大促净利拆解（net-profit-review）
name: 大促净利拆解
description: 输入平台账单与大促参数，输出五层净利拆解与净利率
inputs:
  - gmv: 大促成交额
  - refunds: 退款率（默认 5%）
  - platform_rate: 平台综合扣点（默认 12%）
  - logistics / ads / commission / other / fixed: 各层成本
outputs:
  - 五层金额与净利率
steps:
  1. 导出平台订单账单与财务流水
  2. 按五层口径填参数
  3. 运行 net_profit_layer 脚本
  4. 对照预算与实际，输出差异表

真实团队里，这个技能包接上 7 维度审核器，一次大促复盘从半天缩到 15 分钟；关键是"口径固定"——五层公式写死在脚本里，谁算都一样。

五、可复现步骤

  1. 导出平台订单账单、财务流水与投放报表
  2. 按五层口径建表：GMV、退款、扣点、物流、投放、佣金、杂费、固定分摊
  3. 运行 net_profit_layer 脚本，核对五层结果与净利率
  4. 对照预算与实际差异，定位最大失血层
  5. 写 SKILL.md 与示例输入，沉淀为技能包
  6. 下月大促前用同一脚本跑预算，把拆解结果接进投放入口

大促复盘别只看 GMV。GMV 是面子，净利是里子；五层拆解是那把把面子翻成里子的刀。公式和脚本都摆在这里，拿去用，30 秒算完，下个月就知道该往哪儿补。
